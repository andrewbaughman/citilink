SWIV Citilink API POC

Vanilla JS demo consuming every resource in api-discovery/openapi.json.

This API sends no CORS headers, so this page can only reach it when Chrome is launched with --disable-web-security. Run ./launch-chrome.sh from the poc/ directory instead of opening this file directly — otherwise every button below will show a fetch error.
